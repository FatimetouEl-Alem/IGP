Déploiement
-----------
Site 100 % statique. Copier tout le dossier (fichiers HTML + dossier assets)
à la racine d'un hébergement web : Apache, Nginx, IIS, Netlify, GitHub Pages...
La page d'entrée est index.html. Aucune base de données ni serveur applicatif requis.
Pour tester en local : ouvrir un terminal dans ce dossier puis lancer
    python3 -m http.server 8080
et ouvrir http://localhost:8080
